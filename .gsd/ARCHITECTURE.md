## Overview

The Citizen Resolver System aims to be a full-stack platform. Currently, the codebase consists of a React-based frontend mapping user interactions for a citizen helpline portal. It simulates backend data interactions using a centralized mock REST API via `localStorage` and `setTimeout`. 
The frontend is contained in the `frontend/` directory. The `backend/` directory is currently empty and pending initialization.

### API Simulation Layer (`frontend/src/services/api.js`)
- **Purpose:** Simulates network requests and latency.
- **Dependencies:** Uses `localStorage` configured with `baseState` from `mockData.js`.

### Data Layer (`frontend/src/data/mockData.js`)
- **Purpose:** Stores initial mock schemas for areas, departments, issues, labour, users, and notifications.

## Data Flow

1. User interacts with UI components in React.
2. Component triggers asynchronous methods mapped in `services/api.js` (e.g., `api.createIssue`).
3. The API method fetches structured data from `localStorage`, modifies it, and saves it back.
4. Simulated network delay wraps the return, updating the React state via an event dispatch `portal-state-change`.
